# Báo cáo cuối kỳ

Dành cho bản thảo, nguồn soạn thảo và bản nộp cuối cùng.
Nội dung dự kiến: yêu cầu, cache gốc, thiết kế/thuật toán, đồng bộ, triển khai, phương pháp đo, kết quả, hạn chế, phân công và tài liệu tham khảo.
Đối chiếu yêu cầu giảng viên trước khi chốt. Số liệu phải dẫn đến log và commit có thể tái hiện.
