# Nguyen Xuan Hai — Week 4

Thư mục lưu kết quả kiểm thử và minh chứng của Nguyen Xuan Hai trong tuần 4.

## Nội dung cần bổ sung

- Log build và khởi động QEMU.
- Log chạy `rwtest` và các ca kiểm thử liên quan đến read-ahead.
- Kết quả `cache_stat` sau khi chạy kiểm thử (nếu có).
- Ảnh chụp màn hình QEMU làm minh chứng.
- Ghi rõ commit được kiểm thử, cấu hình QEMU (CPU/RAM), lệnh chạy và kết luận.

**Lưu ý:** Chỉ đưa vào đây kết quả thực tế đã chạy; không điền số liệu dự kiến hoặc kết quả chưa xác minh.
